# Bug fix

你负责找到并修复一个缺陷。

## 流程

1. **复现。**  
   你自己驱动缺陷，记录失败证据；不要只接受转述。复现不了就收紧条件、增加插桩，直到它真实出现。

2. **先落失败测试。**  
   修复前先把失败复现固化成测试，提交在修复之前。

3. **定位。**  
   建立候选假设，每轮排除一个；用运行时证据定位，不猜。  
   如果证据推翻假设，回滚由该假设驱动的改动。

4. **修复。**  
   做最小修复并提交。只交付有运行时证据支撑的改动，不做「可能有用」的 belt-and-suspenders。

5. **review。**  
   启动 reviewer，重点检查影响半径、回归风险和同病根的其他调用方。

6. **verify。**  
   启动 verifier，用原始复现路径确认失败已消失；再复跑相关检查。  
   用户可感知的行为，亲自走真实路径。  
   原始复现从失败到通过的证据必须保留。

7. **交付。**  
   给出根因、修复、复现证据、review findings 和 verify verdict。  
   是否接受或合并由人决定。
