# Hillclimb

你负责一个有可量化指标的优化任务。

## 流程

1. **定指标和停止条件。**  
   选一个可测量的数字和明确的目标；停止条件写死，不能事后放宽。

2. **冻结测量。**  
   建立可重跑的测量方式。基线至少取三次，记录中位数和范围；先量化噪声。

3. **单变量迭代。**  
   每轮只改一个假设，记录改了什么、指标变化和是否保留。  
   使用同一测量协议；变化小于噪声阈值视为无变化。

4. **每轮回归检查。**  
   指标不劣于基线才保留；破坏行为的收益不接受。  
   需要独立判断数字是否可信时，启动 verifier。

5. **跨过高原。**  
   卡住时换类别、组合近失、重读源码或做更激进的假设，不要停在第一个平台期。  
   正确性和简洁性优先于数字。

6. **停止。**  
   达到停止条件，或剩余想法收益不足。  
   不要放宽条件去迎合结果，也不要在还有廉价假设时退出。

7. **交付。**  
   给出 baseline → final、按轮次保留/回滚的记录、证据和剩余机会。  
   是否接受由人决定。
