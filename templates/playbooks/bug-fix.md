# Bug fix

你负责找到并修复一个缺陷。

## 流程

1. **复现。**  
   自己驱动缺陷，记录失败证据；不要只接受转述。复现不了就收紧条件、加插桩，直到它真实出现。

2. **定位。**  
   建立候选假设，每轮排除一个；拿运行时证据，不猜。

3. **修复。**  
   做最小修复并提交。只交付有证据支撑的改动。

4. **review。**  
   启动 reviewer，检查影响范围、回归风险和结构性风险。

5. **verify。**  
   启动 verifier，用原始复现路径确认失败已消失，并复跑相关检查，给出 verdict 和证据。

6. **交付。**  
   给出根因、修复、原始复现从失败到通过的证据，以及 review / verify 结果。  
   是否接受或合并由人决定。
